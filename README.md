# 📂 Projects

## 1. 📍 Region-Wise Analysis | Tableau

An interactive analysis of **Sample Superstore** data designed to evaluate business performance across the **Central, East, South, and West** regions.

### Key Areas of Analysis

- Regional Sales Performance
- Profit Analysis
- Customer Analysis
- Order Analysis
- Product Performance
- Quantity Analysis
- Discount Analysis
- Return Analysis
- Sub-Category Analysis
- Quarterly & Monthly Trends
- Top 5 Analysis
- Product-Level Deep Dive

### Key Insights

- **West** recorded the highest overall sales and profit.
- **Chairs** were a major sales-driving sub-category across multiple regions.
- **Copiers** were a major profitability contributor.
- Monthly analysis revealed important seasonal patterns.
- Product-level analysis identified both high-performing and negative-profit products.
